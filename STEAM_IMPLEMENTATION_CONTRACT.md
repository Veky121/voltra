GET /api/client/servers/{server}/steam -> item steam_status {supported,game,app_id,branch,mode,check_interval_seconds,last_checked_at,last_attempt_at,installed_build,latest_build,update_available,needs_repair,current_job?,jobs:[],node_available}. Jobs {id,operation,status,stage,detail,created_at,started_at,completed_at,error?}. Permission startup.read.
POST /steam/{operation} with {} operations check/update/verify ->202 item steam_job, existing active job reused where compatible. Manual update/verify requires already stopped; no surprise stop. startup.update plus control.start when start-after is requested. No user start-after for manual maintenance in v1.
PATCH /steam {mode:"on_start"|"scheduled"|"off",check_interval_seconds:3600} permission startup.update. Scheduled means periodic checks while running, installs only when stopped; never stops players automatically. interval300..86400.
