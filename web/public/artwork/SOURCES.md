# Original public artwork

All tiles in artwork/ and game-artwork/ are original SVG typography and geometric compositions generated offline by [generate-public-artwork.mjs](https://github.com/Veky121/voltra/blob/main/tools/branding/generate-public-artwork.mjs) from tools/branding/public-artwork-input.json. Run node tools/branding/generate-public-artwork.mjs from the repository root to reproduce them.

No publisher logos, screenshots or marketing imagery are included. Game and product names identify compatible software; their trademarks remain with their owners. Repository licensing applies to the original compositions, not to third-party names or trademarks. Fonts use the viewer's system sans-serif font. Bundled UI fonts and their OFL notices are separate and unchanged. Voltra brand assets are separate and unchanged.

The private .local/private-artwork-backup folder contains removed historical files and is not public artwork or release content. The sources.json ledger records current generated bytes and SHA-256 hashes.
