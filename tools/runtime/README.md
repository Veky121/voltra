# Runtime tools and acceptance notes

This directory contains per-game adapter notes, shared helpers and bounded native acceptance plans. Many notes describe a specific source snapshot or historical run. Read the exact plan and current campaign handoff before running a tool; an old approval or stopped-state report is not current authorization.

For ordinary setup use [Game setup](../../GAME_SETUP.md). For workspace services use [local development](../../docs/LOCAL_DEVELOPMENT.md). Source validation, native startup, persistence and player joining are separate evidence levels. Preserve failed attempts, installed helper bytes and verification limits.
