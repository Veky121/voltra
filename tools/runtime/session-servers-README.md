# SCP:SL, maintained EXILED and Killing Floor 2 source adapters

Source-only stage: `.local/session-servers/profiles.json`, generated by
`node tools/runtime/stage-session-servers.mjs`. Overrides and shared helpers are
owned by root. No Steam depot, runtime binary or release archive was downloaded
while preparing this batch. No native resources were acquired.

The final checkpoint uses full `node tools/runtime/stage-session-servers.mjs`
regeneration so all three embed current helper bytes. Both SCP profiles retain
identical domain metadata/controls; only their installer source snapshots changed.
`--kf2-only` remains available for intermediate review, not a canonical merge.

Run Linux fixtures with `wsl.exe -u root -e python3 tools/runtime/test-session-servers.py`.
They exercise the real Linux secure publication helper on temporary directories,
not a Windows replacement. These fixtures are not native game acceptance.

All 23 original variables, defaults and visibility/editability flags remain.
EXILED gains explicit AUTO_UPDATE=0 for the shared managed-Steam contract, retaining
its original no-update startup behavior. AUTO_UPDATE=1 updates the base server and
re-resolves the chosen EXILED release. Reinstall always honors version selection.

## Explicit acceptance work remaining

No startup, client connection, game query, Steam socket, native config reload,
real plugin load, admin login, persistence, reinstall or normal exit is proved.
The original KF2 startup inverted WebAdmin and emitted `??WebAdminPort`; its
intended toggle is restored through the actual INI instead. EXTRA_FLAGS now
provides literal optional switch arguments, without shell expansion or managed
port/path overrides. Map travel options remain configurable in native files;
MAP_NAME is a map package instead of a command-injection surface.

KF2 source metadata now requires three same-address allocations: primary game,
Steam at primary+12783, and independent query. Conditional WebAdmin requires four.
Primary-relative `offsets:[12783]` reserves the fixed socket before shared-form
automatic query/WebAdmin selection; both optional roles exclude that fixed socket.
The runtime AND installer reject overflow (primary>52752), missing companion,
query/Steam or WebAdmin/Steam collision before configuration/Steam writes. EXTRA_FLAGS
cannot override SteamPort. No invented explicit SteamPort CLI is emitted.

The primary maintained LinuxGSM documentation states the automatic Steam formula
directly at https://docs.linuxgsm.com/game-servers/killing-floor-2 (Ports section,
read2026-10-23). This is the maintainer's own documentation, **not independently
confirmed publisher documentation**: Tripwire's linked official wiki was
inaccessible. Current LinuxGSM executable/stop-mode source identity:
https://github.com/GameServerManagers/LinuxGSM/blob/a477b50018dcd77f0179815d24ca438acff8255f/lgsm/config-default/config-lgsm/kf2server/_default.cfg
does not itself assert the formula. The formula still requires actual native
socket observation; source-level complete allocation requirements do not promote
**not_verified** to runtime acceptance.

SCP configs, permissions, bans and plugins remain below `.config/`; no generated
configuration is overwritten wholesale. EXILED archive data is validated fully
before the first write; symlinks/devices/duplicate paths and expansion over256MiB
are unsupported and fail. Installer preservation is bounded128MiB with16MiB per
existing file; larger operator trees fail explicitly instead of partial backup.
Private Steam user/password/auth and password branches remain fail-closed.

EXILED framework publication now records SHA256/size per managed file inside
`.voltra/exiled-release.json`. Updates replace an existing DLL/PDB/XML only when
the prior receipt owns that path and its current bytes still match the recorded
publisher bytes. Modified or untracked collisions fail with a prerequisite to
back up and explicitly resolve that exact path. This includes importing an older
installation with no ownership receipt: ownership is never silently adopted.
Existing config/default text files remain operator-owned and are preserved.
Obsolete framework files are not deleted. The separate private Microsoft .NET
runtime retains its previous publication semantics, without EXILED ownership rules.

The entire EXILED archive and all destination collisions are checked before the
first payload publication. An exclusive no-follow lock serializes our updates;
secure shared publication retains owner/group/mode. The ownership receipt is
published last in the same rollback transaction. A failed member/receipt/owner
assignment restores previous bytes and owner/group/modes and removes new payload
files. Empty created directories and the private lock may remain. Concurrent
operator byte changes are preserved and reported as incomplete rollback rather
than overwritten. No power-loss atomicity for the whole tree is claimed.
Focused Linux root fixtures exercise actual UID12345/GID12346 publication,
0640 retention, operator collisions, canonical archive duplicates, symlink
parents, post-write failure, receipt failure and owner-assignment failure.
