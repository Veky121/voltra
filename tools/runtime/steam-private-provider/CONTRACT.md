# Private typed Steam worker — source checkpoint

This is a separate source-worker checkpoint with MIT original transport glue, pinned unmodified GPLv2 DepotDownloader source kept separate, and the actual LGPL SteamKit2 package. No DepotDownloader classes are compiled or incorporated into the transport binary. No production caller, capability or private Steam gate is changed. `prepare_only` remains offline: it constructs typed fields and returns `provider_not_enabled`. The new explicit `authenticate_beta` operation constructs a SteamKit session, connects, authenticates with private-FD Guard handling, logs on using the transient refresh token, optionally checks a supplied beta password, disconnects and returns only `session_completed`. This is opt-in code pending root review: no live private authentication has been performed; the separately authorized anonymous metadata result is documented below. Self-tests use synthetic public literals, actual SteamKit protobuf serialization, injected sessions and local private pipes only.

Owned files are confined to this directory, the scoped IPC test, `.local/steam-private-typed-provider/` and a handoff artifact. The exact original DepotDownloader source and GPL license are supplied under `upstream/`; the exact SteamKit package's corresponding source archive is also supplied there. SteamKit package/source provenance and LGPL notices, Apache protobuf-net notices and MIT transitive notices are retained in `licenses/`. Root approved MIT for new original glue; `LICENSE` applies to that glue only, never the separate upstream files. Any content-fork wiring/distribution needs a separate source/license-boundary review. The checked-in NuGet lock includes exact versions/content hashes; package sources are public NuGet only. No stock CLI credentials/console authenticator are wrapped.

Target net10.0 with a checksum-verified official supported SDK, exact global.json version and package lock. The utility has a normal shared1024MiB/4096MiB/0-port lease, SDK/packages public acquisition≤512MiB, no game/runtime-for-games acquisitions. After public restore, build/self-tests run networking-disabled in the existing pinned Debian image. SDK/package version/size/hash receipts and cleanup evidence are retained; no private values go into them.

Protocol: the parent passes only numeric request/event/reply FD IDs. Each private channel is bounded length-prefixed UTF8 JSON, using inherited anonymous descriptors, with nonblocking poll/deadline/cancellation and fixed errors. Credentials/Guard/beta are never argv/env/disk/log fields. Challenge messages carry a random single-use ID and kind, never account email/token text; replies must match the exact active state and cannot be reused. Parent validation is preserved: account/password/Guard values are mapped unchanged after the parent validated their actual original field rules. Beta retains the current independent1024-UTF8-byte/noCRLFNUL/nonpublic-branch rule, including accepted TAB/otherC0/DEL. No trim/normalization/prefix ban is added.

Actual SteamKit AuthSessionDetails and IAuthenticator are used. Beta transport tests serialize and deserialize SteamKit's generated CMsgClientCheckAppBetaPassword through actual protobuf-net, not a handwritten packet mock. The source-only content interface specifies authenticated app/build/depot/manifest/chunk/file identities, staged hash-checked publication and provider-specific receipts. It must never fabricate a SteamCMD ACF/manifest or infer successful content installation from authentication.

Future network acceptance, content implementation and integration require root review and separate legitimately authorized credentials/ownership acceptance. Persistent account stores, stock Console/DebugLog output and publisher exception text are forbidden; typed provider errors remain fixed enums. Cancellation must terminate the private worker before scratch cleanup. No claim is made that RSA/server-side password policies or arbitrary credentials will authenticate merely because local string/packet fidelity passes.

Session transport uses the pinned actual SteamKit `BeginAuthSessionViaCredentialsAsync`, cancellable `PollingWaitForResultAsync`, `SteamUser.LogOn` and `SteamApps.CheckAppBetaPassword` APIs. Server discovery is memory-only; DebugLog is explicitly disabled. Session tokens, account names, branch encryption keys and publisher exception messages never leave the worker. Beta authorization requires OK plus the exact requested branch's 32-byte key; response keys are zeroed and discarded. Empty beta passwords do not make an entitlement claim. `session_completed` proves neither ownership nor installed content. No license/content request API, content downloader, publication receipt producer or Depot-derived code is wired.

The inherited request operation is the only opt-in switch; no environment/argv credential or network-enable switch exists. The total worker deadline remains 30 seconds with 20-second Guard challenges, SIGTERM cancellation, fixed private-channel errors and teardown. Parent must independently enforce admission, legitimately authorized credentials/ownership and bounded process termination; acceptance of real accounts, server rejection policies, network failure/reconnect and content identity remain untested. Transport disposal disconnects the SteamClient and joins its owned callback pump. Offline tests exercise dispatch rejection before factory creation, ordering, exact fields, cancellation before/inside authentication and Guard waiting, fixed-error redaction, beta refusal, actual generated protobuf replies and key erasure. ContentReceipt remains an interface-only future contract, never a fabricated SteamCMD ACF.

`anonymous_metadata` is a separate explicit request operation. It requires null account/password/Guard/beta fields (even empty strings are refused), the existing positive app-ID/parent-validation contract and a valid branch field. It never enters credentials authentication. The actual SteamKit session connects, `SteamUser.LogOnAnonymous` completes, then `SteamApps.PICSGetProductInfo` requests one app with zero access token and no packages. It does not request access tokens, licenses, manifests, chunks or game data. The typed private terminal response whitelists app ID, change number, public/missing-token flags, known OS platforms, branch build IDs/password-required flags, depot IDs/shared-app IDs/architecture and available manifest IDs with nullable reported disk/download bytes. Encrypted manifest values, raw KeyValues, URLs and publisher strings are never published. Metadata is not an entitlement check; `EntitlementVerified` and `ContentDownloaded` always remain false. Build/size fields can be null; no estimate or synthetic SteamCMD ACF is substituted.

Metadata states distinguish available/partial, empty, unknown-app, missing access token, incomplete jobs and HTTP-metadata-required (unsupported external metadata URI is never followed). Available means the whitelist has some data, never that every depot or protected branch is visible. Limits are 64 branches, 128 depots/manifests, bounded raw child counts and a 48KiB projected payload within the private channel's 64KiB frame. Oversize or conflicting identities fail closed. Duplicate branch/depot/manifest identities are refused. Projection uses actual SteamKit PICS KeyValues; fixtures round-trip generated upstream PICS protobuf and invoke the actual package's parser with public synthetic data. The initial metadata source checkpoint had no live request; the one later authorized anonymous result is documented below. The offline operation tests also prove credentials are refused before transport construction, exact connect/anonymous/PICS/dispose ordering, cancellation and fixed failures. Teardown cancels its own callback lifetime and bounds disconnect plus pump join to two seconds; timeout is a fixed error, requiring parent hard-kill before resource cleanup. No production caller/gate is enabled.

Metadata ABI revision: every public 64-bit build ID, manifest ID, disk-byte count and download-byte count is a canonical decimal JSON **string**, backed internally by `MetadataUInt64(ulong)`. Unknown optional values remain null; app/depot/change IDs stay numeric uint32 (within JavaScript's exact range). Strings contain ASCII digits only, no sign, whitespace, exponent, leading zero except the single value `"0"`, and no value above18446744073709551615. The converter rejects JSON numbers rather than silently accepting a rounded JavaScript Number. Noncanonical publisher manifest values are excluded with partial state; malformed supplied build/byte fields become null with partial state. Missing fields are explicitly nullable, never zero-filled. The interface-only future content receipt is not emitted by this worker; any future publisher must apply the same lossless ABI to its 64-bit identities before integration.

One separately authorized live anonymous app3809400 request succeeded using the previous frozen numeric ABI, preserved at `artifacts/steam-private-metadata-3809400-live.json`; its exact raw JSON manifest3659990775896995763 exposed a host JavaScript parse/stringify rounding defect. The raw first success and nonauthoritative lossy derived receipt remain immutable regression evidence. No second live request was used for this fix. New executed C#/private-FD/JavaScript tests use a clearly synthetic fixture with that exact ID to prove string preservation, alongside strict malformed-number tests. `--self-test-metadata-fd N` emits only that public synthetic fixture over the supplied private descriptor, never accepts credentials or constructs a SteamClient; it is a test flag, not a production API or native-success claim. The source ABI revision has offline proof only and does not enable production callers, authentication or game downloads.
