# Banana Shooter, Nuclear Option and Puck

Source owner is game_batch_inventory. Stage with `node tools/runtime/stage-light-games-next.mjs`. The generator writes only `.local/light-games-next/profiles.json`; root reviews and integrates. No client gameplay is inferred.

The original 8, 7 and 9 variables and their defaults remain intact. Banana's account fields are nullable for the anonymous path described by older publisher docs, but the actual first public attempt now returns No subscription. This is an explicit entitlement gate. Private Steam credentials still fail closed through the shared Steam helper before any write or process. Blank GSLT means LAN-only in the publisher documentation, public listing needs an operator-owned token. Native token mapping is unverified. No credential is acquired or fabricated.

The installer downloads only each exact official dedicated-server app: 2406780, 3930080 and 3481440. Normal shared Steam metadata refresh and app_update/validate remain required. Existing selected JSON is restored byte-for-byte, with mode and numeric ownership, even after publisher-update failure. Other data is left to Steam's normal validation behavior, so world/mod/ban directories still require native preservation acceptance.

The launcher uses the existing native console wrapper with literal argv. Nuclear Option and Puck send native PTY Ctrl-C, Banana sends `quit`. Raw native exit codes remain visible. The original Banana recipe forcibly killed its process; graceful quit is a publisher-documented improvement whose native result still needs acceptance.

Both Nuclear and Puck need two allocations. Query defaults remain the original 7777 and 7778. Select an explicit allocated second port. Unallocated or colliding values fail clearly rather than silently changing an operator field. Nuclear ports have native `IsOverride=true` and integer values. Puck's current publisher browser uses TCP on its ping/query port. Unknown JSON settings, mission rotation, mods and ban/admin lists survive managed updates. JSON duplicate keys, non-finite values, oversized files and symlink escapes are rejected.
