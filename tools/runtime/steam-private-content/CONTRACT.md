Root approved this replacement architecture after rejecting the separate GPLv2 fork/dependency combination. Original orchestration uses actual SteamKit2 APIs directly; no DepotDownloader code, classes or translated expressions are copied or compiled. The already acquired GPL archive is immutable research reference only, excluded from this worker and its distribution. This is not a clean-room or legal compatibility guarantee. The superseded proposal is preserved under .local/steam-private-content for audit.

## Actual implementation sequence

Independent original code will implement typed authenticated license-list/package/app access and PICS selection; exact requested branch/OS/architecture/language/shared/DLC depot eligibility; actual depot decryption keys, manifest request codes, SteamPipe server discovery and scoped CDN auth; real DownloadManifestAsync/DownloadDepotChunkAsync; chunk bounds/checksums and final SHA1/localSHA256; private scoped verified cache; descriptor-confined staging, publication journal, rollback and provider-specific receipt. Actual SteamKit API/source documentation, not GPL implementation expressions, defines these adapters. No FreeToDownload metadata inference or automatic free-license activation. No anonymous/public/previous-build fallback for denied private content. Actual acquisition is not proven by a source adapter or injected fixture.

The private CDN adapter preserves real account licensing, fresh entitlement revision, selected identity, actual depot key and manifest request code before choosing an official discovered HTTPS443/nonproxy/appallowed endpoint with valid Host/VHost. Server.Type is not an authorization predicate. CDN credentials are decided before the first HTTP request: an OK empty scoped lookup permits the SDK's documented optional absence; a valid nonempty token is bound to app/depot/actual URL VHost and used. Denied lookup, expired/mismatched token and HTTP401/403 stop with no alternate server, auth retry, anonymous fallback or downgrade. Offline fixtures execute actual SteamKit manifest ZIP/protobuf and AES+ZIP chunk code for both optional and scoped-token queries. This is not private-account acceptance proof.

First checkpoint compiles the actual SteamKit APIs and executes coordinator failure/hash/selection tests with injected adapters; publication remains gated until its secure implementation is separately exercised. This is an iterative implementation checkpoint, not interface-only completion. Later checkpoints must implement the full private cache/publication path below before any capability can be enabled. Unsupported prerequisites produce explicit failures, never fabricated success or a SteamCMD ACF.

## Private process and lossless protocol

Only inherited numeric request/event/Guard-reply descriptors carry operations; account/password/Guard/beta/CDN tokens never appear in argv, environment, logs, account files, filenames or events. Preserve the exact parent field policies and beta1024-UTF8-byte/noCRLFNUL/nonpublic-branch policy without trimming or extra character bans. Copies retain actual typed SteamKit AuthSessionDetails/IAuthenticator use and single-use correlated challenges. All64-bit identities/offsets/bytes are typed internally and canonical decimal strings in public JSON. Parent admission, fresh job/scope, bounded deadlines/cancellation, exact worker-group hard-kill after teardown failure and fixed errors remain mandatory. No credential requests or live authentication/downloads are authorized during source/offline work.

## Private cache and secure publication contract

Game-content cache is private node-isolated storage scoped by server and opaque authorization owner, app/depot/manifest/chunk. Directory0700/files0600, correct UID/GID, no publicOSS cache or cross-owner reuse, no persistent passwords/Guard/tokens/keys. Fresh real access checks precede cache access; possession of a cache blob is not entitlement. Corruption/quota failure is explicit.

Before writes, preflight complete manifest path/chunk coverage, budgets and disk space including staging+rollback reserve. Confine all target/cache/stage/journal/receipt paths with descriptor-relative no-follow/beneath traversal and ownership checks; Path.GetFullPath is not sufficient. Reject traversal/absolute/drive/UNC/control/case collisions/duplicate paths/special files. Linux publisher links are now implemented through a merged publisher graph and native nofollow link operations: exact relative targets must resolve inside known publisher paths, with escapes, cycles, link parents and unknown operator targets rejected. Windows publisher links fail explicitly. No existing/unowned or operator-modified file is overwritten. Prior file SHA256/size/mode/UID/GID and owned directory identity are rechecked under the publication lock. Preserve protected config/save/mod roots and UID/GID/modes. Existing uploaded/SteamCMD assets need explicit migration review, never automatic ownership adoption.

Use same-filesystem staging/backups, complete hash verification, fsync and durable per-file rename journal. Update only unchanged prior receipt-owned paths; preserve operator files. Test rollback after each mutation including post-replace failure and interruption recovery. Failure cannot claim rollback succeeded if restoration fails. Nonce/request digest/server/owner scope bind durable job admission and terminal receipts; old/wrong-scope receipts cannot authorize replay. Resumption may reuse verified chunks after fresh authorization, never old credentials or an old success for a new job.

Provider steamkit-depot-v1 has its own versioned private receipt binding job/request/scope, exact publisher app/build/depot/manifest/platform/branch/language identities and complete file SHA1/SHA256/size/mode/ownership inventory. Large inventories use private0600 confined receipt files with count/digest and bounded event summary. Parent independently validates the receipt and actual publication; entitlement_verified requires real access and publication_committed requires durable commit. native_acceptance_verified remains false until real native proof. No fabricated SteamCMD ACF or installed-state marker.
